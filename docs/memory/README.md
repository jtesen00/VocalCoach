# Memoria del proyecto

Contexto para retomar el trabajo sin releer todo el historial, tanto para personas como para asistentes de IA. Orden de lectura:

1. [status.md](status.md): dónde estamos y qué sigue.
2. [project-context.md](project-context.md): qué es el producto, principios y preferencias del equipo.
3. [decisions.md](decisions.md): registro breve de decisiones, con enlaces a los ADRs.
4. [conventions.md](conventions.md): cómo se escribe y organiza el código.
5. [learnings.md](learnings.md): problemas técnicos encontrados y cómo se resolvieron.

**Mantenimiento:** al cerrar una tarea relevante, actualizar `status.md`, añadir las decisiones nuevas a `decisions.md`, lo aprendido a `learnings.md` y la entrada correspondiente en [`../CHANGELOG.md`](../CHANGELOG.md). Mantener los archivos cortos: el detalle va en `planning/` y `adr/`.
